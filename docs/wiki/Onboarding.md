# Onboarding

1. Install Python 3.12+, Git and Docker Desktop.
2. `git clone https://github.com/not-clover/distributed-telemetry.git && cd distributed-telemetry`
3. `make dev`, then `make test`. Both should pass.
4. Read: README → `docs/PROJECT_PLAN.md` → `docs/adr/` → `proto/cellpulse/v1/telemetry.proto`.
5. Open the Project board and filter by `assignee:@me`.
6. Do the onboarding issue: add yourself to `CONTRIBUTORS.md` in your first PR.

**Windows users:** use WSL2 so `make` works.

**Stuck for more than 20 minutes?** Post in Discussions → Q&A. Asking early is part of the working agreement.
